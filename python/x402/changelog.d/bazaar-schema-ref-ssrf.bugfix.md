`validate_discovery_extension` now rejects a Bazaar discovery extension `schema` containing a `$ref`/`$id` that is not a same-document (`#`-prefixed) JSON Pointer fragment. `schema` arrives in the client's payment payload, and `jsonschema`'s default registry resolves any other `$ref`/`$id` form via `urllib.request.urlopen`, fetching both `http(s)://` and `file://` targets before the instance is ever validated -- a server-side request forgery / local file disclosure vulnerability (CWE-918).
